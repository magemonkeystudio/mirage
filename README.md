# Development

If you wish to use Mirage as a dependency in your projects, Mirage is available through our repository.


```xml
<repository>
    <id>magemonkey-snapshots</id>
    <url>https://repo.travja.dev/snapshots</url>
</repository>
...
<dependency>
    <groupId>studio.magemonkey</groupId>
    <artifactId>mirage</artifactId>
    <version>1.0.2-R0.6-SNAPSHOT</version>
</dependency>
```
